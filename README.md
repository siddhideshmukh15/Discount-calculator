# Discount Calculator

## Description
A simple Python program that calculates the discount amount and final price of a product.

## Features
- Accepts original price and discount percentage.
- Calculates discount amount.
- Displays the final price.
- Validates price and discount inputs.

## Technologies Used
- Python 3

## Concepts Learned
- Variables and user input
- Arithmetic operators
- If-else statements
- Type conversion
- `round()` function
